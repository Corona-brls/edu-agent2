# 演示脚本

## 启动顺序

第一个终端启动后端：

```powershell
cd "D:\edu agent"
.\.venv\Scripts\Activate.ps1
uvicorn backend.main:app --reload --port 8000
```

第二个终端启动前端：

```powershell
cd "D:\edu agent"
.\.venv\Scripts\Activate.ps1
streamlit run frontend/app.py
```

浏览器打开：

```text
http://localhost:8501
```

## 演示路线

1. 打开“学生端”，展示课程介绍和专题导航。
2. 输入 `这个课程智能体能帮我做什么？`，展示系统能力回答和引用。
3. 输入 `5G NAS 认证流程有哪些关键风险点？`，展示课程知识问答。
4. 输入 `我想做基于区块链的隐蔽通信，怎么设计实验？`，展示结构化实践方案。
5. 输入 `有没有可以作为漏洞检测样例的 CVE？`，展示工具选择 `vuln_lookup`。
6. 输入 `3GPP TS 24.501 里 NAS 安全相关内容在哪里？`，展示工具选择 `standard_lookup`。
7. 输入 `请总结一篇知识库不存在的论文结论。`，展示低证据拒答。
8. 切换到“教师端”，展示总提问数、拒答次数、模块分布、最近问题和 FAQ。
9. 切换到“工具状态”，展示 5 个本地工具。
