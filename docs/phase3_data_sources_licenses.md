# 数据来源与许可证说明

## 本地课程资料

- `knowledge_base/` 和教师上传文档由课程维护者提供，仅用于本地教学演示。
- 上传文档会写入本机 SQLite 与 Chroma，不会自动公开或上传到外部服务。

## 外部 Connector

| 来源 | 用途 | 说明 |
|---|---|---|
| Semantic Scholar | 论文标题、作者、摘要、年份、DOI/链接 | 只缓存公开元数据和 API 返回摘要 |
| arXiv | 预印本标题、作者、摘要和链接 | 使用公开元数据，不下载全文 |
| NVD | CVE、CVSS、CWE、发布日期、更新时间和链接 | 使用公开漏洞元数据 |
| 3GPP/标准来源 | 标准编号、版本、官方链接、本地上传状态 | 不抓取受版权保护全文 |
| GitHub | 开源项目元数据 | 默认关闭，启用后只使用公开仓库元数据 |
| `datasets/competitions` | 教师维护竞赛题目 | 本地教师数据，不抓取不稳定网页 |

## 许可证与引用原则

- 外部资源页面展示标题、摘要、标签、来源链接、缓存状态和更新时间。
- 事实性推荐必须带来源；纯模型建议在创新模块中标记为模型建议。
- 报告、截图和导出文件不得包含 API Key、私有全文或未授权学生个人信息。
