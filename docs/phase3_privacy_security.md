# 隐私与安全说明

## 敏感配置

- 真实密钥只写入本机 `.env`。
- `.env.example` 只保留空占位。
- API、页面、日志和测试报告不得显示 API Key。

## 身份与权限

- 后端根据 JWT 确定 `user_id`、角色和课程/班级范围。
- 学生不能调用 Connector 同步、知识库删除、聚类管理、教师统计和 MCP 调试接口。
- 教师只能查看自己课程和班级，管理员可查看全部。

## 不可信内容处理

- 上传文档、外部资源、Observation 和工具结果全部视为不可信数据。
- Safety Guard 过滤提示注入，Action Guard 拦截非法动作、越权工具和高风险操作。
- 外部 URL 只允许 `http://` 与 `https://`。

## 导出安全

- FAQ CSV 导出对 `=`, `+`, `-`, `@`, tab 和回车开头内容进行公式注入防护。
- 教师统计默认返回聚合数据，不暴露其他学生完整问题。

## 网络安全教学边界

系统只支持授权教学、防御分析、本地实验设计和资料检索。不得请求对公网目标的攻击步骤、凭据窃取、持久化控制、绕过检测或真实利用链执行。
