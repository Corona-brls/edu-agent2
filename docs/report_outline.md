# 报告提纲

## 1. 项目背景

面向网络安全实践课程，构建一个可演示、可解释、可扩展的 MCP-RAG 教学智能体系统。

## 2. 参考项目

- EduAgent：教育场景 RAG 架构与教师反馈。
- TeaChat：中文教学链路与多 Agent 思路。
- openai_rag_project：最小 RAG 闭环与拒答机制。

## 3. 系统架构

说明 FastAPI、Streamlit、SQLite、本地知识库、TF-IDF 检索和工具注册层。

## 4. 核心功能

- 学生问答
- 引用回答
- 低证据拒答
- 实践指导
- 教师统计
- FAQ 汇总

## 5. 后续升级

升级到标准 MCP Server、真实知识库、向量数据库、多 Agent 编排和部署方案。
