# 课程智能体人工验收手册（二阶段）

## 1. 手册用途

本手册参照[原人工验收手册](人工验收手册.md)的格式，但面向**阶段 0–6V 升级后的当前项目**。目标是让你或后续 Codex 在**内置浏览器真实打开 Streamlit 页面、登录、点击并观察**，按固定顺序检查原有课程智能体和升级功能，而不是再开发一套验收运行器。

每个编号项都要记录：**账号、页面路径、原样输入、实际点击、页面结果、来源/引用、状态和证据**。普通 pytest、API 直调、旧报告、页面源码和服务状态只能辅助诊断，**不能替代本轮要求的页面点击**。曾有“升级最终验收完成”的历史报告；那是当时的证据结论，不自动等于本轮每一个人工项 PASS。特别是 Practice 探索草案此前只有真实 Provider 正例配合离线 HTTP 测试，**本手册要从学生页面真实提交并观察结果**。

验收用两名学生和一名教师，覆盖：使用说明与课程简介、九篇内置教材、课程有据问答、外部 MCP/Agent 工具、资料库、通用 DeepSeek 问答、两种实践指导、实验进度、创新启发、教师统计/热点/FAQ、上传与发布生命周期，以及会话/权限边界。**125% 浏览器缩放已由你明确删除，不再安排，也不写成测过。**

## 2. 验收前须知

### 2.1 本轮数据与写入边界

原手册使用新隔离数据库，因此每个账号初始密码都可重置；本轮为查看之前安装的九篇教材、复用之前创建的三个账号，使用当前 `.env` 指向的正式**演示课程数据**：`backend/data/app.db` 及现有知识/向量目录。两种方案不能混用。本轮的提问、评价、进度、卡点、创新会话、教师同步记录与测试文档会**真实持久化**。你已在当前对话授权 Codex 按本手册在演示课程完成这些正常验收操作，不必在每个页面再次询问。权限仅限三个指定演示账号、当前演示课班、本轮唯一测试文档，以及为恢复这三个演示账号而执行的受控密码重置；不是修改其它用户或九篇教材的授权。

仅对本轮唯一标记的**新测试文档**做上传、索引、发布、撤回或删除。九篇内置教材不得重索引、撤回或删除；已有真实热点簇不得为测试随意合并、拆分。不要运行 `python -m backend.auth.seed`：它不只是登录操作，会写演示资料。也不要改正式 `.env`、数据库表、模型超时或真实来源开关来“凑通过”。

### 2.2 真实资料、模型与隐私

启动时使用现有 `scripts/start_live.ps1`。它只在本次后端进程中开启 arXiv、Semantic Scholar、NVD、GitHub、RFC Editor 等真实来源及 Agent 工具门，单 worker、无 `--reload`。FastAPI 启动时会尝试建立 stdio MCP 会话；不另开 MCP 终端。当前 `.env` 有旧的 `ENABLE_MCP_SERVER=false` 字段，但当前 MCP 网关不读取它；以教师“运行状态”的**实际工具连接**为准。

截至 2026-10-19，已对 `.env` 做过**仅非秘密状态**的只读核对：`LLM_PROVIDER=deepseek`、`DEEPSEEK_MODEL=deepseek-flash`，DeepSeek 和 NVD Key 字段非空，Semantic Scholar Key 字段为空。字段非空不证明凭据有效，之后若配置变化以本次运行状态为准。不得把 Key、Token、代理值或 `.env` 正文写进手册、提示词、截图和报告。课程有据问答和课程有据实践的 DeepSeek 正例受两道门共同保护：本次后端进程的课程许可清单必须包含 `course_id=1`，且页面“允许本次请求将我选择的最小课程片段交给外部模型处理”必须由执行者为该次请求明确勾选。你已明确授权本轮把 `demo-course` 已发布、非敏感教材的**最小必要片段**用于这些规定正例，Codex 可自动勾选，无需再次询问；这不授权其它课程、未发布资料、个人数据或整篇教材外发。公开资料 Agent、Portal 和不需要课程内容的通用问答仍保持该框不勾选。任一道门关闭时，`MODEL_CONTEXT_NOT_AUTHORIZED` 是预期的安全拒绝，不得误判为学生课班越权。

真实来源和模型会发生公网请求，模型可能计费。每个规定的正例**先正常提交一次**，串行操作，不并发、不人为制造 429/超时、不无限重试。若遇第三方限流、空内容或网络故障，按第 13 节归类并保留结果，不用模板、旧缓存或另一来源冒充本次 live。已经成功的真实来源，无须为了截图机械重发。

### 2.3 内置浏览器执行规则

Codex 后续执行时，使用本机 `http://127.0.0.1:8501` 的**内置浏览器**操作可见控件。优先按本手册的单会话顺序“退出当前账号→登录下一个账号”，不依赖多个浏览器窗口共享身份。页面截图若只能显示在工具输出、没有真实保存成文件，报告写“浏览器现场观察”，**不能声称已保存截图文件**。可以用只读服务状态/日志解释问题，但不得以 API 调用或数据库查询代替本应点击的页面功能。

每项先记录结果再继续。普通业务失败时暂停**依赖该结果的链路**，其余互不依赖项仍可继续，最终不能宣布全部通过；若发现跨账号数据泄露、越权写入、误删教材、密钥暴露等安全或数据完整性问题，立即停止相关操作并报告。你已明确授权本手册规定的正常登录、账号首次改密**包括最终提交**、测试文件上传/索引/发布/撤回、教师审核、有界公开来源和模型调用，以及在明文凭据确实不可恢复时按《项目升级指导》的窄命令恢复指定演示账号；无需为这些动作逐项复问。Codex 不得再以“需要你亲自改密”为由停下：由 Codex 生成不同强密码、输入本机页面并提交；若浏览器工具本身有不可绕过的硬限制，则按升级指导中已获授权的存储层恢复路径完成演示账号恢复，而不是要求用户代填。密码只进入 Git 忽略的本机凭据附页，不进聊天、报告、截图或终端输出。模型或第三方失败记 `PENDING`，不自动追加付费/公网调用；未知凭据不猜，使用受控恢复而不是新建替代账号。

## 3. 启动项目

### 3.1 终端 A：后端与真实来源

确认项目 `.venv` 已存在，然后在第一个 PowerShell 窗口运行：

```powershell
Set-Location -LiteralPath 'D:\edu agent'
$env:EXTERNAL_MODEL_COURSE_ALLOWLIST = '1'
& .\scripts\start_live.ps1
```

保持终端开启。此脚本会为本次后端进程启用真实资料来源，启动 `127.0.0.1:8000` 上的单 worker FastAPI；前一行只在本次进程树把 `demo-course` 加入外部模型课程许可清单，不修改 `.env`，也不替代页面逐请求勾选。**不要用旧 `scripts/start_backend.ps1` 代替**：旧脚本使用 `--reload`，且不负责打开 live 门。如果只因本机执行策略阻止脚本，可在同一 PowerShell 先设置上述进程变量，再用 `powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\start_live.ps1`，不要修改全局执行策略。

### 3.2 终端 B：前端

在第二个 PowerShell 窗口运行：

```powershell
Set-Location -LiteralPath 'D:\edu agent'
& .\scripts\start_frontend.ps1
```

内置浏览器打开 <http://127.0.0.1:8501>。如果 8000/8501 端口已被其他旧服务占用，先识别并处理旧服务；不能把连到旧实例的页面算本轮证据。

### 3.3 健康与真实工具预检

可在另一个 PowerShell 窗口只读执行：

```powershell
Invoke-RestMethod http://127.0.0.1:8000/api/health
```

随后**必须登录教师并在页面**检查“运行状态”或“教学管理 → 运行状态”。记录下表，不以命令输出替代页面：

| 项目 | 本轮要看到/如何判断 |
|---|---|
| 资料记录、课程检索 | SQLite/Chroma 可用；不可只有页面框架而后端报错。 |
| 工具连接 | MCP 实际可用；若显示本地降级，MCP 正例暂不能判通过。 |
| 生成方式、模型服务 | 页面应显示“模型服务”“已配置”；具体 `deepseek`/模型名在后续真实回答中核对。若是本地模板，真实模型项记 `PENDING`。 |
| 公开工具 | 论文、NVD、GitHub、RFC 等显示可用；“已启用”**不等于**来源网站已成功返回。 |

只有第 7、8 节的真实查询取得正确公开来源、状态与 URL，才能记来源现场成功。启动/状态检查失败先处理环境，再做业务项；不要通过增加验收框架绕过去。

已只读核对当前配置的数据库，三个账号均启用且都属于 `demo-course` / `demo-class`。下表的 ID 仅供教师“学习轨迹”输入，不是认证信息。

| 角色 | 用户名 | 用户 ID | 密码/当前状态 |
|---|---|---:|---|
| 教师 | `teacher_demo` | 1 | 只使用本机私有凭据附页中标为已验证的现用密码；不得假定初始化密码仍有效。 |
| 学生 A | `student_demo` | 2 | 只使用本机私有凭据附页中标为已验证的现用密码；始终复用原账号，不新建学生 3。 |

恢复时为每个需要恢复的账号生成彼此不同的一次性强密码并设置 `must_change_password=true`，随后由 Codex 在本机页面正常登录、自动提交另一组不同的最终强密码、退出并用最终密码重登；若页面工具硬性阻止自动提交，则由已授权窄命令使用同一存储层入口直接设置最终密码和 `must_change_password=false`，并仍须用正常页面登录验证。把**实际已生效且执行者确实知道**的最终密码记录在 `md/人工验收手册二阶段-本机凭据.local.md`；该路径已被 Git 忽略但并未加密，因此不得提交、推送、写入主手册、报告、截图、聊天或终端日志。无需再请求用户输入或批准密码操作；对外只记录成功/失败、用户 ID 未变、角色/启用/课班未变及旧 token 已失效。

## 5. 验收总顺序与继续条件

按下表执行；它专为**一个内置浏览器会话**设计。多窗口可加快切换，但不能成为通过标准。每一行完成后先填第 14 节相应编号，再进入下一行。

| 顺序 | 身份与任务 | 前置/切换点 |
|---:|---|---|
| 0 | 启动；三账号正常登录/首次改密预检 | 逐个记可用性；缺失账号只阻断依赖项，不把其它可做项一起停掉。 |
| 1 | 教师：运行状态、九教材、上传**未发布**测试文档、逐源同步 | 做完退出。 |
| 2 | 学生 A：确认未发布文档不可见 | 做完退出。 |
| 3 | 教师：只发布本轮测试文档 | 做完退出。 |
| 4 | 学生 A：发布后检索/引用、课程问答、各 Agent 工具、资料库、通用问答、实践、实验、创新、安全边界 | 做完退出。 |

## 6. 登录、改密与账号切换预检

先读取本机私有凭据附页，只使用确已验证的密码。缺少现用密码的指定演示账号先执行《项目升级指导》的受控恢复，不重复猜密码。随后在内置浏览器左侧“账号登录”依次登录 `teacher_demo`、`student_demo`、`student_demo2`，观察身份和角色，再逐一退出。出现首次改密提示时，由 Codex 在“当前密码/新密码/确认新密码”自动输入并完成最终提交，无需用户接手。未改密前课程功能被阻断是正确行为，不可当成课程故障。学生侧栏应有“课程学习”“创新探索”“使用帮助”，**没有**“教学管理”“运行状态”；教师有教学管理和运行状态。不要把教师也能看到学生页面误判成越权，角色导航按当前产品实际设计。

账号恢复前后都要核对 `teacher_demo=1`、`student_demo=2`、`student_demo2=3`，角色、`enabled`、`demo-course/demo-class` 成员关系和业务表计数不变；只允许密码哈希、`must_change_password` 和 `token_version` 发生预期变化。课程/班级若只有一组授权，学生页可能以纯文本自动显示而不是出现选择框；教师进入“教学管理”时先显式选择“当前课程”=`demo-course`，班级按需要选 `demo-class`。预检后用可登录的教师开始或恢复后续步骤。

完整通过标准：三个原账号都能以正常登录进入、应改密者改密后才能访问业务、退出后只显示登录提示；页面没有沿用上一个人的问答/会话。少一个账号即本项 `PENDING`，但可继续其它独立项。只读 API 或直接签发 Token 不能替代浏览器登录预检；受控存储层恢复只负责建立可用凭据，也不能代替本项页面登录证据。

## 7. 教师前置准备（`teacher_demo`）

### 7.1 运行状态与九篇教材

进入“教学管理”，先在“当前课程”选 `demo-course`、班级选 `demo-class`；核对第 3.3 节的运行状态。再开“课程资料”，在**独立的**“知识库课程”框也选 `demo-course`。课程文档中应找到九篇 `INDEXED` 且“已发布”的内置教材，包括《5G NAS安全专题方法卡》《区块链与隐蔽通信专题方法卡》《大语言模型安全专题方法卡》等。文档总数可以超过九。页面不显示 catalog 审核字段，因此这里只验文件与索引/发布状态；九篇经用户审核的历史依据仍见 catalog/2C 报告，不冒称浏览器重验审核过程。记录教材状态，不改动九篇的索引或发布。

### 7.2 准备唯一测试文档，上传并索引但暂不发布

用记事本创建一个新的 UTF-8 Markdown 文件，例如 `人工验收-20261019-01.md`。如果同名/同标记已被上传，换一个**本轮唯一**后缀，并在报告中写明实际值。示例内容：

```markdown
# 人工验收：NAS 合成日志

MANUAL-NAS-20261019-01：这份材料只用于本地教学验收，不含真实用户、密钥、运营网或公网目标。
在隔离的合成日志中比较正常认证序列和重复旧序号消息的处理结果。
每条记录保留输入编号、初始状态、预期转移、实际转移、拒绝原因和处理时延。
评价指标为接受率、拒绝率、误报率和未分类数；模拟结论不能推广成真实网络漏洞。
```

在“教学管理 → 课程资料”上传这个**新测试文件**，点击“上传并切片”。本轮用户已明确授权 Codex 通过内置浏览器选择和上传这份指定的非敏感样例，无需逐项复问；仍须遵守届时工具对文件上传的规则。展开它对应的文档编号，确认先为“待索引／未发布”；点**该文档**的“手动重建索引”，刷新直到“已索引／未发布”。记录文件名、文档编号、标记和任务结果。**此处不要发布**，先去第 8.1 节检验学生不可见。不能用已经发布的九篇教材代替这条发布前负例。若内置浏览器本身无法选择本地文件，记 `PENDING/浏览器环境`，不要用 API 上传冒充页面验收。

### 7.3 教师逐来源同步：实际联网与本地目录分开

进入“教学管理 → 外部资料更新”，先看来源启用表，再在表单中依次选来源、资料类型、查询词，结果数量设 `1`，每项点一次“同步资料”，读本次结果与最近同步记录：

| 编号 | 来源 | 类型 | 查询词 | 教师页核对／学生页再核对 |

## 13. 如何判断问题性质与中止范围

### 13.1 可以初步判为产品问题（`FAIL`）

- 账号/课班串号、学生看到另一人的会话/进度或教师操作入口；
- 未发布、撤回后的测试文档仍作为**新**学生证据出现；
- 资料来源编号、文档 ID/hash、公开 URL 绑定错误；
- 模板候选被标成真实“模型建议”，或本地缓存/目录被写成 live；
- 可用资料存在却稳定找不到，或按钮无响应/保存后立即丢失；
- 安全拒绝失效、泄露密钥或提供真实攻击步骤。

页面出现“当前账号无权执行此操作”时不能只凭文案认定课班权限缺陷。先脱敏记录响应的 `error_code` 和 `course_reference_status`：`MODEL_CONTEXT_NOT_AUTHORIZED + disabled_by_user` 表示本次未勾选，`blocked_by_policy` 表示课程未进许可清单，这两种都应保持 403/零模型调用，但页面必须明确说明双门原因；`COURSE_FORBIDDEN`、`CLASS_FORBIDDEN`、`AUTH_REQUIRED` 或 session/token 错误才进入账号、课班或会话缺陷诊断。把政策拒绝笼统投影成“账号无权”本身属于需要修正的展示缺陷，不能靠放宽后端双门解决。

先记录原问题、账号、时间、页面、状态、来源卡，再只停依赖这项的后续链；**越权、泄密、误删教材、数据污染**应立即停止本轮高风险操作。

### 13.2 第三方/环境待验（`PENDING`）

例如 Semantic Scholar/GitHub/NVD 429、DNS/TLS/超时、MCP 未连上、DeepSeek 空响应或浏览器下载失败。保留页面原始提示；模型和公网不要循环重试。一次内置浏览器截图不能落盘，只能称“观察未持久化”，不算产品失败也不算截图证据 PASS。本轮无需即时追问或自行补测，最终报告列明待验项即可。

### 13.3 正确的安全行为及条件项

不存在论文、离题或攻击请求被拒答；3GPP 只给目录元数据不提供全文；未发布资料不可见；模型建议标“待验证”；无证据就拒答/说明缺口，这些是正确边界。真实 Planner 未进入 `REQUIRES_INPUT`、当前无实验任务/可安全操作的聚类、历史坏标签会话不存在，则对应条件项记 `NOT_COVERED/NOT_TRIGGERED`，不能写 `FAIL` 或 `PASS`。

### 13.4 体验改进（`UX`）

文案生硬、来源说明难读、等待提示不清、窄窗口水平溢出、输入状态不易辨认等可单列为改进。功能可用但体验不佳，不应掩盖真实安全/数据问题。可在浏览器支持时试普通 1024×768、768×768 视口观察是否可读；这不是已删除的 125% 缩放测试，也不做像素级承诺。
